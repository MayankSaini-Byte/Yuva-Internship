# Data provenance

Dataset: Palmer Penguins simplified dataset.
Creator credits: Kristen Gorman and Palmer Station LTER; package by Allison Horst, Alison Hill and Kristen Gorman.
Documentation: https://allisonhorst.github.io/palmerpenguins/
Source CSV: https://raw.githubusercontent.com/allisonhorst/palmerpenguins/main/inst/extdata/penguins.csv
Dataset citation: https://doi.org/10.5281/zenodo.3960218
Original study: https://doi.org/10.1371/journal.pone.0090081
Data license: CC0, as stated by the project documentation.
Retrieved: 2026-09-10.

Acquisition: direct download timed out in the execution environment. The source CSV was accessed using web retrieval. All source lines 0–344 were recovered from overlapping responses, de-duplicated by source line number, ordered and saved without altering field values. Thus this is a source-value-preserving CSV snapshot, not a claim of byte-for-byte identity with the remote file. No synthetic data were introduced. Validation confirmed 344 rows and eight columns, expected categories, missingness counts and numeric domains.

Source row in the flagged-observation table means one-based data row excluding the CSV header. Analysis preserves the source order.
